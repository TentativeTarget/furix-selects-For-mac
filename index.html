项目分拣：一次过完一整场展会

  • 「新建项目」先选父文件夹，填项目名与客户名，工具会建好 展会A/客户1/ 等文件夹，并把项目状态写进 .furix-project.json。下次用「打开项目」选这个文件夹即可继续。
  • 再点「选择 SD 卡根目录」：A/B/C/D 等子目录的照片会一起读进来并按文件名配对 JPG + RAW，SD 卡只读，不会被改动。
  • 「场次与客户」按拍摄时间划时间段并指派客户。改了开始/结束时间，照片归属会自动重算；自动建议只是起点，随时可以手动改。
  • 在网格空白处按住鼠标拖出选框即可框选（Ctrl/Shift 拖为追加），再配合 P 标记。
  • 「按客户导出」可选当前筛选 / 所选 / 全部已分客户，只勾 JPG 用于发客户初筛，只勾 RAW 并选「客户/选图集」用于进 Lightroom。

客户回传：编号 → 选图集

  • 客户回 PANA9034、9034、或只回后几位 034 都认；按他自己那批文件名匹配，同一串数字在不同客户那里指向不同照片。
  • 同一个后缀在他那批里对上多张时会列候选让你点，没确认的不写盘；缺号会列出来，若这个号出现在别的客户清单里会提示你。
  • 默认只把 RAW 复制进 客户X/选图集/，可勾选同时复制 JPG；回传过的照片在网格里带「回」角标。

成品集 / 打包 / 台账

  • 客户回传后自动建好 客户X/成品集/，LR 直接往这里导出。
  • 「打包交付」会扫描底片（初筛 JPG）、选（回传 RAW）、成品三组数字；成品比回传少就拦住，勾「照打」才能继续。
  • 包名 展会名_客户名.zip，扁平结构，放到 项目/交付/；重打即覆盖。
  • 台账写在项目父文件夹的 交付台账.csv，单号按年、按类型（订单/玩拍）分开计数；「台账统计」里能看到今年单数、底片、成品和每个项目的明细。

省空间：清交付包 / 往年归档

  • 交付面板底部能勾选删除 交付/ 里的 zip，腾出空间；「已交付」记录保留，行内标「包已清理」，随时可重打。
  • 「归档 / 恢复」先把客户素材打进 客户X/归档.zip（不压缩、保目录结构），逐条校验文件名与大小后才允许删原图。
  • 删原图要连点两次确认；删了之后用「恢复」可以解回原处，项目里的客户、场次、单号都还在。

散片 / 直出 / 水印

  • 不成套、不算订单的活不用建项目：直接「快速选片」打开文件夹 → 选 → Ctrl E 导出，不占单号也不进台账。
  • 导出对话框左边是预览、右边是选项；水印分「文字」「图片」两个勾选，只勾一个就是单水印，都勾就是双水印，位置 / 边距 / 大小 / 不透明度各自独立。
  • 尺寸可选「原图（不限制长边）」满分辨率直出；同名文件可选每次问我 / 覆盖 / 加后缀 / 跳过，选「每次问我」会先弹窗列出来。
  • 加水印会重新编码成 JPEG（复制原图、WebP 会被禁用），EXIF 不保留；RAW 等无法解码的文件按原图复制并提示张数。

重复照片

  • 同名（-2、(1)、 副本 会被剥掉）+ 同样大小 → 认定同一张；大小不同不算。
  • 筛选栏「隐藏重复」每组只留最外层、无后缀的那张；角标 重 N 标出重复组。
  • 完全同名的副本共享标记：给外面那张按 P 或打星，子目录那张自动跟着变；-2 副本不参与同步。

接入旧项目

  • 项目已经按客户分好文件夹、但没有项目文件时，用空白页的「接入已有项目」。
  • 自动扫出客户、项目名/类型/日期、每个客户的底片·选·成品张数；成品集里有图就默认标为「已交付」（交付包删了也算）。
  • 可以选「不计入台账」或「从第 N 单开始补进今年台账」；接入只新建项目文件，不动照片。

EXIF 与分类

  • 选中照片后，检查器显示机身、镜头、焦段（含 35mm 等效）、光圈、快门、ISO 与拍摄时间。
  • 侧栏「EXIF 分类」可按机身、镜头、焦段、光圈筛选；排序菜单支持拍摄时间、焦段和光圈。打开文件夹后会在后台读取 EXIF，未识别到的照片归入「未知」。

关于文件

  • 支持预览 JPG、PNG、WebP、AVIF、GIF、BMP 等格式。RAW 会自动提取文件内嵌的 JPEG 预览用于选片，不修改原图；提取不到时显示占位，仍可照常打标记。HEIC、TIFF 不能预览，但可以打标记并复制原文件。
  • 标记会自动保存在浏览器，并在可写时写入照片目录的 .furix-catalog.json，下次打开同名图库自动恢复。
  • 直接写文件夹需要 Chrome / Edge 的文件夹授权。其他浏览器会自动改为打包 ZIP 下载。
  • 导出 JPEG / WebP 时按长边缩放，原图不会被修改；RAW 始终按原文件复制，避免用内嵌预览降级画质。XMP 标记文件会与照片同名放在一起。
